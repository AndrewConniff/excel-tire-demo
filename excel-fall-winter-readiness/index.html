Step-by-step run order

  1. Open workbook from OneDrive and confirm AutoSave is on.
  2. Start on Sales table for trend summary and chart.
  3. Move to Inventory for stock-risk highlights and delivery cutoff check.
  4. Move to AutoService for capacity and wait-time insight by region/week.
  5. Use Sales + Targets for actual-vs-target variance explanation.
  6. Close with Feedback + workbook wrap for call-ready summary bullets.

Where to run each prompt

  1. Demo 1: Excel workbook open on Sales sheet (tblSales). Chat alternative: attach workbook in Copilot Chat.
  2. Demo 2: Excel workbook open on Inventory sheet (tblInventory). Chat alternative: attach workbook or Inventory.csv.
  3. Demo 3: Excel workbook open on AutoService sheet (tblService). Chat alternative: attach workbook or AutoService.csv.
  4. Demo 4: Excel workbook with Sales + Targets context. Chat alternative: attach workbook and request summary table.
  5. Demo 5: Excel workbook on Feedback sheet plus workbook context. Chat alternative: attach workbook or Feedback.csv.

Copy-ready prompts

Demo 1: Summarize trends
WHERE THIS PROMPT HAPPENS: Excel workbook, Sales sheet (tblSales), Copilot pane in Excel.
Using tblSales, summarize the top 5 trends over the last 13 weeks.
Focus on category and department movement by week and by region.
Demo 1 follow-up
WHERE THIS PROMPT HAPPENS: Same place as Demo 1 (Sales sheet in Excel).
Create a line chart of weekly Net Sales (CAD) by Department using Week Ending on the x-axis.
Demo 2: Highlight key data points
WHERE THIS PROMPT HAPPENS: Excel workbook, Inventory sheet (tblInventory), Copilot pane in Excel.
In tblInventory, highlight rows where Category is Winter Tires and Weeks of Supply is below 1.5.
Then sort these rows by Next Delivery Date ascending.
Demo 2 follow-up
WHERE THIS PROMPT HAPPENS: Same place as Demo 2 (Inventory sheet in Excel).
Which stores in that highlighted set are not restocked before 2026-11-20?
Demo 3: Retrieve insights
WHERE THIS PROMPT HAPPENS: Excel workbook, AutoService sheet (tblService), Copilot pane in Excel.
From tblService, show Bay Utilization % by Region by Week Ending.
Create either a PivotTable or chart that makes region changes easy to compare.
Demo 3 follow-up
WHERE THIS PROMPT HAPPENS: Same place as Demo 3 (AutoService sheet in Excel).
Which region is over capacity, and when did that start?
Demo 4: Explain meaning
WHERE THIS PROMPT HAPPENS: Excel workbook with Sales and Targets sheets available in the same file.
Compare 13-week actual Net Sales (CAD) from tblSales to 13-Week Net Sales Target (CAD) in tblTargets by Region and Department.
Create a summary with Actual, Target, and Variance %.
Demo 4 follow-up
WHERE THIS PROMPT HAPPENS: Same place as Demo 4 (Sales + Targets context in Excel).
Explain the variance formula in plain language and identify which areas are behind target and by how much.
Demo 5: Corporate wrap
WHERE THIS PROMPT HAPPENS: Excel workbook, Feedback sheet (tblFeedback), then workbook-level Copilot context.
From tblFeedback, list the top 3 Auto Service feedback themes and include short example quotes.
Demo 5 follow-up
WHERE THIS PROMPT HAPPENS: Same place as Demo 5 (Feedback/workbook context in Excel).
Write 5 bullets summarizing this workbook for a regional operations call.

  4. Keep answer-key.md and sample-data/answer-key-metrics.json open for quick validation.

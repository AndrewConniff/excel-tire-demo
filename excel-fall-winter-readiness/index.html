Main follow-along flow (Excel first)

1. Open Canada-Wide-Winter-Tire-Sales-Weather-2023-2026.xlsx in Excel (OneDrive/SharePoint, AutoSave on).
2. Keep Copilot pane open in Excel.
3. Run prompts E1-E5 in order.
E1 - Trend summary
WHERE THIS PROMPT HAPPENS: Excel, workbook "Canada-Wide-Winter-Tire-Sales-Weather-2023-2026.xlsx", sheet "Data", table "tblWinterHistory".
Summarize the top 5 trends in tblWinterHistory across seasons, regions, snowfall, and winter tire sales.
E2 - Build comparison chart
WHERE THIS PROMPT HAPPENS: Same Excel workbook/table as E1.
Create a chart comparing weekly Winter Tire Sales (CAD) and Snowfall (cm) by region.
Use a layout that is easy to explain in 60 seconds.
E3 - Rank demand risk
WHERE THIS PROMPT HAPPENS: Same Excel workbook/table as E1.
Which regions appear highest risk for winter tire demand pressure this season, and why?
Return 3 ranked regions with brief evidence.
E4 - Executive bullets
WHERE THIS PROMPT HAPPENS: Same Excel workbook/table as E1.
Write 5 executive bullets summarizing the most important findings from this workbook.
E5 - Action table
WHERE THIS PROMPT HAPPENS: Same Excel workbook/table as E1.
Create an action table with columns:
Action | Owner Role | Target Date | Reason.
Use workbook findings to populate at least 5 rows.

Excel fallback prompts

Fallback A
WHERE THIS PROMPT HAPPENS: Same Excel workbook/table as E1.
Highlight any unusual week-over-week changes in Winter Tire Sales (CAD) by region and explain what may be driving them.
Fallback B
WHERE THIS PROMPT HAPPENS: Copilot Chat with this workbook attached (alternative path).
Using this workbook, draft a short regional operations update for this week with top risks and next actions.

Copilot Chat research -> build a new workbook in Excel

Use this section when you want to show research-first workflow, then move into Excel for structure and charts.
R1 - Research themes
WHERE THIS PROMPT HAPPENS: Copilot Chat (browser/app), no workbook required.
Research public information themes on winter tire demand patterns in Canada.
Give:
1) key demand drivers,
2) weather-related factors,
3) regional differences,
4) likely signals to track this winter.
Include concise source references where possible.
R2 - Generate starter CSV
WHERE THIS PROMPT HAPPENS: Copilot Chat.
Create a starter dataset I can paste into Excel as CSV with these columns:
Week Ending, Region, Avg Temp (C), Snowfall (cm), Winter Tire Units Sold, Winter Tire Sales (CAD), Notes.
Generate 20 realistic fictional rows in YYYY-MM-DD and CAD conventions.
R3 - Clean table in Excel
WHERE THIS PROMPT HAPPENS: Excel, NEW blank workbook, sheet "ResearchData" after pasting CSV.
I pasted a CSV table on sheet ResearchData.
Convert this into a clean Excel table and suggest a useful table name.
R4 - Build chart and summary
WHERE THIS PROMPT HAPPENS: Excel, same new workbook and table from R3.
Create one chart and one 4-bullet summary from this table that I can share with leadership.
R5 - Outlook + Teams handoff text
WHERE THIS PROMPT HAPPENS: Excel Copilot or Copilot Chat with your research table/chart context.
Draft:
1) a short Outlook update email, and
2) a short Teams channel post
based on this research table and chart.
